readme

This directory includes most major files generated as a part of the 16S rRNA Amplicon sequencing pipeline used to analyze Mini Gradient Array, iChip, and filter samples from Fayetteville Green Lakes from August to November 2025.

Certain files are not available in this directory due to file size. This includes:
- Reads for SRA, which are available at NCBI via BioProject PRJNA1533977
- Intermediate QZA files containing filtered reads (Reads.qza, Reads_filt.qza), which can be regenerated by running the qiime2 pipeline on Reads for SRA if downloaded from NCBI.
- Intermediate gg_2024_09_backbone.v4.nb.qza file.
- Picrust2 output files, which can be regenerated with the R picrust2 pipeline.

Note that this amplicon sequencing pipeline was run in two steps with two main R scripts.
1. qiime2 was used to process raw reads, see qiime2-Timeseries/ AmpliconSeq_q2 HTML file and Macalady9_BisanzPipeline
2. the output of qiime2 was analyzed in MGA_16S_pipeline in the parent directory which includes all figures and statistics appearing in the final manuscript and supplementary. This also contains the picrust2 run.
